# Opportunity Solution Tree

A simple editor for opportunity solution trees: outcome, opportunities, solutions, experiments.

## Features

- Four levels: outcome, opportunity, solution, experiment
- Add, edit and delete nodes inline
- Copy as Markdown, export JSON, or print to PDF
- Saved locally

## Usage

Open `index.html` in a browser. There is nothing to install and nothing to build.

Your data is saved in the browser's local storage and never leaves your machine.

## Stack

HTML, CSS and JavaScript in a single file. No dependency.
